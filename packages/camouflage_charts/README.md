# camouflage_charts

Charts for Camouflage, drawn without a chart library: `CamoSparkline` now, with `CamoLineChart`, `CamoBarChart` and
`CamoPieChart` to follow in M11. A chart follows the skin and the theme through tokens, the parts it reuses and a
preset per skin name (`CamoCharts.registerPreset`); it adds nothing to the skin contract.
