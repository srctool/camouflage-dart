## 0.1.1

- A full README (features, getting started, usage, themes, other skins) and an example for pub.dev; topics and the documentation link in the pubspec.
- Accessibility: `CamoTouchSemantics` gives small controls (buttons, icon buttons, field actions, segments, tabs, navigation items, button-group buttons, split-button parts) 48 x 48 semantics without changing layout or painting; icon-only navigation items carry their label; table rows are named; the select-all box has a full-size target.
- New `CamoClipRRect`: a `ClipRRect` that clips only what is painted, so enlarged touch targets inside a rounded container are not cut off.
