# Example

The [example app](https://github.com/srctool/camouflage-dart/tree/main/example) in the repository shows every component, with the skin, brand and light or dark switched live; the README of this package has a complete getting-started walkthrough.

A minimal app with a skin is in the example of any skin package, for instance [`camouflage_skin_minimal`](https://pub.dev/packages/camouflage_skin_minimal/example).
