# camouflage_core

**Camouflage core.** The components, the theme and the skin contract of Camouflage: 52 components that take their look from a swappable skin and theme. Visually neutral and with no Material dependency; pair it with a skin package.

```dart
CamouflageProvider(skin: minimalSkin, theme: minimalLight, child: const MyApp())
```

Part of [Camouflage](https://github.com/srctool/camouflage-dart), a UI library whose look comes from a swappable skin and theme, for Flutter and Kotlin Multiplatform. Documentation: https://github.com/srctool/camouflage.
