# camouflage_skin_cupertino

**Cupertino skin.** Apple's design language for Camouflage, from the widgets layer: Classic and glass surfaces (blur, tint and specular edge), opacity feedback, HIG colors.

```dart
CamouflageProvider(skin: cupertinoSkin, theme: cupertinoLight, child: const MyApp())
```

Part of [Camouflage](https://github.com/srctool/camouflage-dart), a UI library whose look comes from a swappable skin and theme, for Flutter and Kotlin Multiplatform. Documentation: https://github.com/srctool/camouflage.
