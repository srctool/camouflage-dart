# camouflage_skin_material

**Material skin.** Material 3 for Camouflage, drawn from the widgets layer (no material.dart): Paper surfaces, ink ripple, M3 proportions.

```dart
CamouflageProvider(skin: materialSkin, theme: materialTheme(), child: const MyApp())
```

Part of [Camouflage](https://github.com/srctool/camouflage-dart), a UI library whose look comes from a swappable skin and theme, for Flutter and Kotlin Multiplatform. Documentation: https://github.com/srctool/camouflage.
