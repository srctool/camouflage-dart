# camouflage_skin_fluent

**Fluent skin.** Fluent 2 for Camouflage: Solid, Acrylic and Mica surfaces, Subtle feedback, density that follows the input.

```dart
CamouflageProvider(skin: fluentSkinDefault, theme: fluentTheme(), child: const MyApp())
```

Part of [Camouflage](https://github.com/srctool/camouflage-dart), a UI library whose look comes from a swappable skin and theme, for Flutter and Kotlin Multiplatform. Documentation: https://github.com/srctool/camouflage.
